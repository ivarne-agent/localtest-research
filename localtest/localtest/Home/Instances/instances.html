Storage instances

Query GET /storage/api/v1/instances with a test user's or a service owner's token. Every field is Storage's own parameter; empty fields are left out. The page's address keeps the search, so it can be bookmarked or shared.

Token

Through /Home/GetTestUserToken: production Authentication signs the user in. A user's query must name the instance owner (instanceOwner.partyId or instanceOwner.identifier).

Through /Home/GetTestOrgToken: production exchange/maskinporten?test=true derives the org from the organisation number. A service owner's query must name org or appId.

Filters
Dates

Each filter repeats: created=gte:2026-10-01 and created=lt:2026-11-01 give a range. Operators are Storage's: gt, gte, lt, lte, eq.
